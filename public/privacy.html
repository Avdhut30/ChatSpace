Chatspace

Privacy information

Last updated: August 6, 2026

Information used

Chatspace uses your email for authentication and stores the profile information you provide, such as display name, username, optional mobile number, and profile photo. It also stores messages, room memberships, reactions, stories, and files you choose to share.

Authentication and storage

Authentication, database records, realtime presence, and uploaded files are processed by Supabase. Passwords are submitted directly to Supabase Auth and are never stored as plaintext by Chatspace. The website is delivered through Vercel.

Visibility

Conversation data is restricted by membership rules. Mobile numbers are optional and are intended to be visible only to the account owner and existing conversation contacts. Never post sensitive financial or identity information in chat messages.

Security contact

Report a vulnerability privately through GitHub Security Advisories.
