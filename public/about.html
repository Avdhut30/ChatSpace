About Chatspace

Independent open-source communication software

Chatspace is an original realtime chat application maintained by Avdhut30. It provides private direct messages, invite-only groups, personal spaces, stories, and secure file sharing using React, Vercel, and Supabase.

Independent identity

Chatspace is not affiliated with, endorsed by, or impersonating Telegram, WhatsApp, Google, Microsoft, or any other messaging provider. References to familiar interface patterns describe design inspiration only.

Transparent source

The application source is publicly available at github.com/Avdhut30/ChatSpace. Chatspace never asks users to install software, provide payment-card details, or grant remote access to a device.
